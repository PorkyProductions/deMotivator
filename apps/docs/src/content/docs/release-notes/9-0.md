# WELCOME TO DMV9

For the frontend user, this update provides a few small UI tweaks, and a desktop and mobile app. However, for our developers, this is a major update that completely brings the old codebase into the 21st century. We now use Vite + Svelte for the frontend, and Capacitor provides the backend. This update should make DMV much easier to maintain and scale as we move into the future.

p.s. Linux builds for the desktop app coming coon 🤪
