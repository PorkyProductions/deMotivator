# Welcome

This site is the central docs home for the `(de)Motivator` monorepo.

## What lives here

- Package docs for `demotivator` and shared utilities.
- Web app implementation and ops notes.
- Release notes and change tracking.

## Authoring docs

Write docs with Markdown in `apps/docs/src/content/docs/`.

Use folders for major sections:

- `package/`
- `web-app/`
- `release-notes/`
