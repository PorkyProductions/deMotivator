Welcome to **(de)Motivator** — a satirical insult generator built by [PorkyProductions](https://github.com/PorkyProductions). Press a button, receive an insult. It's that simple (and that brutal).

The app is free to use at **[demotivator.web.app](https://demotivator.web.app/)** and works on desktop and mobile browsers. A free PorkyProductionsID account unlocks additional features like stat tracking, achievements, and the leaderboard, but you can start generating insults without one.

## What's Inside

The app has several pages, all accessible from the slideover navigation launcher on the right edge of the screen:

| Page | What It Does |
| ---- | ------------ |
| **Home** | The main event — press the big red button to generate a random insult. |
| **Insult Browser** | Browse, search, favorite, and share every insult in the app. |
| **Leaderboard** | See who has generated the most insults across all users. |
| **Settings** | Customize which insult packs are active, toggle profanity, set word limits, and more. |
| **Account** | View your profile, stats, achievements, and manage your account. |
| **v1.0** | A preserved copy of the original (de)Motivator for nostalgia purposes. |

### Navigation Behavior

- In its default state, the launcher shows a **hamburger menu icon** so first-time users can quickly identify it as navigation.
- Hovering (or keyboard focusing) the launcher expands it to show a clearer menu affordance before opening.
- Clicking or tapping opens a full-screen slideover menu with large centered links for easier navigation on both desktop and mobile.
